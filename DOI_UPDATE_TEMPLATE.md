## Manuscript Code and Data Availability

The minimal reproducible implementation and full tabular reproducibility package
are publicly available at:

```text
https://github.com/eyelashonhercheek/geodt-rule-assisted-provenance
```

The archived release is available at:

```text
https://doi.org/10.5281/zenodo.20279191
```

The repository is released under the MIT License and provides minimal demo
inputs, the full released tabular dataset, normalization rules, field inventory,
regenerated linkage outputs, and code for UID generation,
evidence-operator-based candidate generation, conservative fallback,
hierarchical status assignment, validation, and provenance tracing. The
full-release workflow regenerates the 1400-row linkage table from the released
baseline and analytical-record workbooks and verifies that the regenerated rows
and summary statistics match the reported results. The released dataset contains
project-generated rock-sample analytical records and does not include
confidential, personally identifiable, or restricted-location information. The
tabular data are intended for public archival release under a CC BY
4.0-compatible data license.
