## Reproducibility Statement

The repository provides two validation levels. First, a small anonymous demo can
be run with:

```bash
python examples/validate_expected_results.py
```

Second, the full manuscript-level release can be validated with:

```bash
python examples/generate_full_linkage.py
python examples/validate_full_release.py
```

The full linkage generator reads the released baseline and analytical-record
workbooks, regenerates all 1400 linkage-result rows, and confirms that they
match the published `linkage_results` sheet. The full-release validator reads
the published `.xlsx` files using only the Python standard library and checks
that the released inputs, regenerated linkage outputs, and summary sheets
reproduce the reported manuscript-level summaries. The expected validation
output is:

```text
Full-release validation passed.
Input analytical records: 1400
Baseline samples released: 100
Linkage result rows: 1400
verified: 440
strong_candidate: 123
candidate_level: 378
unresolved: 459
```
