# Demo Data

The CSV files in this folder are anonymous, simplified, minimal examples for the paper demo.

They represent three object levels:

- `outcrops_demo.csv`: outcrop-level entities
- `samples_demo.csv`: sample-level entities linked to outcrops
- `analytical_records_demo.csv`: analytical records linked to samples

These files are:

- anonymized demo data
- simplified representative examples
- intended only for the minimal runnable repository

These files are not:

- the full project dataset
- the private production dataset
- a complete release of the original system data

The full system and full data are not publicly released in this repository.
