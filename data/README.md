# Demo Data

The CSV files in this folder are anonymous, simplified examples for the paper demo.

They represent the minimal data needed for association-layer provenance recovery:

- `outcrops_demo.csv`: outcrop-level provenance anchors.
- `baseline_samples_demo.csv`: the reference sample space used for candidate recovery.
- `analytical_records_demo.csv`: fragmented analytical records to be reassociated with baseline samples.
- `expected_linkage_results_demo.csv`: expected status and candidate outcomes for the demo records.

The analytical measurement values are not used as matching evidence. The demo uses identifier, source/section, stratigraphic, and lithological fields to illustrate candidate generation, conservative fallback, status assignment, and traceable output.

These files are not the full project dataset or a release of the private production data.
